# Security

Send suspected vulnerabilities privately to the maintainers. On GitHub, use **Security → Report a vulnerability** when private vulnerability reporting is enabled. For a self-hosted instance, contact its operator through their private support channel.

Include the affected version or commit, the relevant route or feature, the impact, and steps to reproduce using synthetic data. Keep passwords, API tokens, session cookies, private keys, and user data out of the report. Allow the maintainers time to investigate before public disclosure.
