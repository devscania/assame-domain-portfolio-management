# Contributing

Use the [README](README.md) to set up a local instance. Run lint, type checking, and the relevant tests before proposing a change. Include migration files with schema changes and explain any compatibility impact for existing installations.

Use synthetic records and provider fixtures in tests, screenshots, and bug reports. Share steps to reproduce and the relevant error message after removing private data. Report suspected vulnerabilities through the process in [SECURITY.md](SECURITY.md).
